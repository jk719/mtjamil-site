# mtjamil.com

A personal website for SAT Math tutoring—classes, one-on-one sessions, lessons, and an interactive whiteboard.

## Purpose

mtjamil.com is a tutoring site that helps students prepare for the SAT Math section. It showcases services, hosts lesson content, and provides tools like an interactive whiteboard for live sessions.

## Features

- **Classes** — Group SAT Math classes and schedules
- **One-on-One Tutoring** — Book and learn about private sessions
- **Lessons** — Video lessons and study materials
- **Whiteboard** — Shared whiteboard for live tutoring

## Tech Stack

- **Next.js** — React framework with App Router
- **TypeScript** — Type-safe JavaScript
- **Tailwind CSS** — Styling

## Getting Started

### Prerequisites

- Node.js 18+
- npm, yarn, pnpm, or bun

### Run locally

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for production

```bash
npm run build
npm start
```

## Project structure

- `src/` — App router pages, components, and styles
- `public/` — Static assets
